# Comment Rule

Do not write comments in code. No inline comments, no block comments, no doc comments, no TODO comments. Write no comments of any kind.

Name functions, variables, types, and files so clearly that comments are unnecessary. If a comment feels necessary, the code is not clear enough — rewrite the code.

The only exception is a build tag or a required annotation that the language or toolchain mandates (e.g. `//go:generate`, `// +build`). These are directives, not comments.
